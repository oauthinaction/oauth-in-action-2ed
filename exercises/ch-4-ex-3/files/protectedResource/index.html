OAuth in Action Produce Resource - localhost:9002

Produce protected resource

This server exposes the OAuth-protected endpoint GET http://localhost:9002/produce .

Send a valid access token in an Authorization: Bearer ACCESS_TOKEN header. Invalid tokens receive a structured 401 invalid_token response.

The exercise is to filter the response by exact scope membership: fruit, veggies, and meats each control their matching list independently. A valid token still receives 200 and all three keys; ungranted categories are empty.

The OAuth client performs this call server-to-server, so no browser CORS library or external asset is required.
