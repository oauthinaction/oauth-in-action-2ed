OAuth in Action Favorites Resource - localhost:9002

Owner-bound Favorites resource

This server exposes GET http://localhost:9002/favorites .

Send a valid access token in Authorization: Bearer ACCESS_TOKEN. The completed exercise reads the persisted resource_owner from that validated token record and selects Alice's or Bob's favorites. It does not trust owner input from the client request and does not filter categories by scope.

Warning: Alice/Bob selection on the authorization page is an insecure exercise fixture, not authentication. A real server must authenticate the resource owner before binding identity to an authorization grant.

Invalid tokens receive 401 invalid_token. The OAuth client calls this endpoint server-to-server, so no CDN, Node dependency, or browser CORS library is required.
