OAuth in Action Protected Words API - localhost:9002

Protected Words API

All operations use http://localhost:9002/words with a Bearer access token.

Words operations and required OAuth scopes
Operation HTTP method Required scope Successful response
Read words GET read 200 JSON
Append a word POST write 201 empty body
Remove the last word DELETE delete 204 empty body

The starter validates tokens but intentionally leaves per-operation scope enforcement as the exercise. The completed version returns 403 for an insufficient valid scope.
